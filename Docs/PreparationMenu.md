# 전투 준비와 패턴 연습

전투 지역에 들어가면 곡별 배경 위에 몬스터별 패턴 개요를 보여준다. 준비 화면은 전투 계획·현재 HP·장착 장비를 읽으며, 무기를 패턴이나 특정 박자에 배치하는 기능은 없다.

| 위치 | 표시 / 동작 |
|---|---|
| 위 | WEAPON MASTER · 다섯 현의 조종자, 곡 이름, 테마, BPM, 스테이지 번호 |
| 상단 HP | 현재 플레이어 HP / 모든 몬스터가 공유하는 현재 적 HP |
| 몬스터별 한 줄 | 도감의 원형 몬스터 아이콘, 이름, 해당 몬스터 도감 버튼 |
| 패턴 카드 | 도감 패턴 아이콘, 이름, Response 리듬, 자동으로 발동하는 장착 무기 아이콘 |
| 아래 | 현재 장착한 다섯 무기의 등급별 이미지·강화 단계·지원 행동, 연주 시작 버튼 |

패턴 카드는 이번 전투 계획에 실제 등장하는 패턴만 표시한다. 같은 몬스터의 같은 패턴이 여러 번 나와도 카드는 하나다. 해당 패턴 안에 현재 지원하는 행동이 하나라도 있으면 무기 아이콘을 표시하며, 여러 입력에 대응하는 무기도 장착 슬롯당 한 번만 표시한다. 지원 무기가 없으면 **발동 무기 없음**을 표시한다. 아래 장비 표시와 패턴의 무기 표시는 읽기 전용이다.

패턴을 누르면 이름과 함께 연습 확인 창을 연다. **돌아가기** 또는 Esc는 목록으로 돌아가며, **연습 시작**은 선택한 패턴의 Call·Response를 원래 BPM으로 반복한다. 확인 창이 열린 동안 뒤쪽 목록과 연주 시작 버튼은 입력을 받지 않는다. 연습 중 **메뉴 → 패턴 목록으로**를 누르면 준비 화면으로 바로 돌아온다. 연습의 HP·판정·방어막·공명·연속 성공은 매회 초기화되며 탐험의 HP·적 HP·골드·보상·장비·전투 계획은 유지된다.

준비 화면의 **메뉴 → 패턴 연습**도 이 목록으로 돌아온다. 몬스터별 도감 버튼은 해당 종족을, 상단 **도감**은 전체 목록을 연다. 등장 횟수 등 상세 계획은 **메뉴 → 몬스터 패턴**에서 확인한다.

## 화면과 이미지

1280×720 Canvas와 SafeArea를 기준으로 몬스터 세 마리의 패턴을 한눈에 보여준다. 행 높이는 화면 높이에 맞춰 조절하고 최대 네 행을 기준으로 공간을 나눈다. 더 많은 행이나 좁은 화면에서는 가운데 목록을 세로로 스크롤하며 상단과 장비·시작 버튼은 고정한다. 16:10에서도 같은 구조를 사용한다.

| 용도 | Resources 아래 경로 |
|---|---|
| 현재 곡 배경 | `BBSB/StageAssets/<곡 ID>/background` |
| 몬스터 아이콘 | `BBSB/Codex/Monsters/<몬스터 ID>` |
| 패턴 아이콘 | `BBSB/Codex/Patterns/<패턴 ID>` |
| 플레이어 초상 | 기존 PlayerMotion의 `idle_0`, 없으면 전투 초상 |

아이콘이 없으면 기존 준비 초상·몬스터 idle·전투 초상, 그마저 없으면 텍스트를 사용한다. 기존 `BBSB/PreparationArt/player`와 `BBSB/PreparationArt/Monsters/<ID>` 전용 초상 및 임포터도 유지한다. 무기 그림은 `WeaponIconGraphic`이 기존 `WeaponBattleGraphic`의 실루엣을 재사용한다. 글자·리듬·HP·아이콘 위치는 코드로 구성한다. 배경과 음원 설치는 [StageAssets.md](StageAssets.md)를 참고한다.

## 검증

PlayMode 회귀 검사는 세 몬스터의 실제 전투를 준비한 뒤 16:9·16:10·작은 안전 영역에서 행·버튼의 화면 내 배치와 겹침, 자동 발동 무기 표시, 도감 입력 복구, 연습 확인·취소·중복 시작 방지, 반복 연습과 목록 복귀 시 전투 상태 보존을 검사한다. 실제 렌더와 입력 감각은 Unity Editor의 PlayMode에서 확인한다.

무기 이미지의 실제 소켓에 행동별 색을 표시한다. 소켓 수는 등급으로 정하며 강화는 수치만 바꾼다. [무기 이미지 설치](WeaponArt.md)를 참고한다.
