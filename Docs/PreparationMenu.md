# 전투 준비 화면


현재 배경은 해당 곡의 `BBSB/StageAssets/<ID>/background`를 전투 화면과 함께 사용한다. 예전 공용 `preparation-background.png`는 더 이상 불러오지 않는다. [에셋 설치 안내](StageAssets.md)를 참고한다.

전투 지역에 들어가면 `BattlePreparationView`가 레퍼런스의 VS 구도로 화면을 채운다. 맵·타이틀·실제 연주 화면은 각자의 레이아웃을 유지한다. 준비 화면은 음악이나 공격을 재생하지 않으며 기존 전투 계획·무기 배치·플레이어 HP·공유 적 HP를 읽기만 한다.

## 배치와 동작

| 위치 | 표시 / 동작 |
|---|---|
| 왼쪽 위 | 무기 배치 → 기존 편성 화면 / 연습 모드 → 현재 배치로 연습할 패턴 선택 |
| 가운데 위 | 실제 스테이지 단계, 곡 이름, BPM |
| 오른쪽 위 | 전체 몬스터 도감 / 탐험 메뉴 |
| 좌우 HP | 현재 플레이어 HP / 모든 몬스터가 공유하는 현재 적 HP |
| 왼쪽 | 플레이어 정지 초상과 실제 장착한 다섯 무기의 큰 실루엣 |
| 오른쪽 | 해당 전투의 몬스터 1~3명. 인원이 늘면 옆으로 나누어 배치 |
| 가운데 | VS 장식과 큰 연주 시작 버튼 |
| 아래 | 이름·이명. 각 몬스터 옆 도감 버튼은 해당 종족 상세를 바로 연다 |

연습 모드의 패턴을 선택하면 해당 패턴을 현재 무기 배치로 무한 반복한다. 전투의 HP·보상은 바꾸지 않는다. 기존 연습 메뉴의 **배치로 돌아가기**는 편성 화면으로 돌아가고, 거기서 **준비로**를 누르면 VS 화면으로 돌아온다. 무기 배치·도감·메뉴를 둘러봐도 전투 계획을 다시 추첨하지 않는다.

Canvas의 1280×720 기준과 SafeArea를 사용한다. 16:10에서는 세로 공간이 늘어나며 상단 버튼과 HP는 위쪽에, 초상·이름과 시작 버튼은 화면 비율에 맞춰 배치된다. 캐릭터 초상 크기는 준비 화면 전용으로 설정하므로 `PlayerMotionDisplay`의 전투 지면·발 위치나 실제 연주의 캐릭터 크기를 바꾸지 않는다. 이명은 `BattlePreparationView.Epithet`에서 조정한다.

## 이미지

각 곡의 배경은 별도 에셋 ZIP으로 전달한다. ZIP의 `Assets` 폴더를 프로젝트에 병합하면 스테이지 ID에 따라 자동으로 연결된다. 배경·음원 바이너리는 Git에 포함하지 않는다.

| 용도 | Resources 아래 경로 | 현재 파일 / 권장 규격 |
|---|---|---|
| 준비 배경 | `BBSB/StageAssets/<곡 ID>/background.png` | 생성 원본 1672×941, 불투명 PNG, 약 16:9 |
| 선택적인 플레이어 전용 초상 | `BBSB/PreparationArt/player.png` | 현재는 없음. 투명 PNG 1024~2048 권장 |
| 선택적인 몬스터 전용 초상 | `BBSB/PreparationArt/Monsters/<몬스터 ID>.png` | 현재는 없음. 투명 PNG 1024~2048 권장 |

전용 초상이 없으면 플레이어는 기존 `idle_0` 스프라이트, 몬스터는 기존 `MonsterAttacks/<ID>/idle`을 재사용한다. 이들도 없을 때는 기존 전투 초상으로 대체한다. 컨셉 이미지나 레퍼런스 이미지는 런타임 초상으로 쓰지 않는다. 배경은 비율을 유지해 화면을 채우며 넘치는 부분만 화면 바깥에서 잘린다.

버튼 프레임·아이콘·체력바·빛 줄기·VS 장식은 `PreparationGraphic`이 그린다. 글자와 HP를 배경에 굽지 않으므로 곡·몬스터·현재 체력이 바뀌어도 재생성할 필요가 없다. 무기는 기존 `WeaponBattleGraphic`을 준비 화면에서만 크게 그리며 실제 장비 교체를 반영한다.

`StageAssetImporter`는 곡별 배경을 Texture로, `PreparationArtImporter`는 준비 화면 전용 초상을 Sprite/Single/Full Rect로 설정한다. 원본 알파를 사용하며 mipmap 없음, Bilinear, Clamp, 비압축, 최대 2048이다. 기존 임포트 설정은 보존한다. 새 파일은 임포트한 뒤 준비 화면에 다시 진입하면 읽는다.

## 검증

PlayMode 회귀 검사는 준비 화면과 전투 화면의 분리, 기존 초상 연결, 실제 HP 비율, 16:9·16:10·작은 안전 영역에서 버튼의 화면 내 배치와 겹침, 종족 도감 바로 열기·닫기 시 입력 복구, 연습 선택 목록, 전투 계획과 배치 보존을 확인한다. 이 작업 환경에는 Unity Editor가 없어 실제 화면 렌더와 PlayMode 실행은 별도로 확인해야 한다.
