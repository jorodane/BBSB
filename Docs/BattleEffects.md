# 공격 이펙트와 원거리 무기

## 설치

최신 `codex/roguelike-foundation` 코드를 받은 뒤 `BBSB_effects_ranged_v1.zip` 안의 `Assets`를 프로젝트에 합친다. 기존 `BBSB_weapon_art_v1.zip`에 추가하는 팩이다. 이미지와 새 한글 글리프를 포함한 폰트를 함께 넣는다. Inspector 연결이나 씬 수정은 필요 없다. 원거리 장비는 상점·보상에서 등장하며 시작 장비 다섯 개는 기존 구성을 유지한다.

새 이미지는 미국 카툰풍의 실제 RGBA 투명 PNG다. 이미지·음원은 사용자가 업로드하고 코드는 Git으로 배포한다. 원본에 체크무늬나 배경색을 넣지 않으며 런타임 색 제거도 하지 않는다.

## 원거리 무기

| 무기 | 일반 | 희귀·영웅에서 추가 | 전설에서 추가 |
|---|---|---|---|
| 활 | Tap 속사: 10 피해 | Hold 당겨 쏘기: 완료 시 30 피해 | Flick 부채꼴 사격: 합계 18 피해 |
| 석궁 | Flick 강철 볼트: 22 피해 | Tap 속사 볼트: 12 피해 | Dive 회피 사격: 끝 박에 떼면 26 피해 |
| 마도봉 | Shake 마력탄: 18 피해 | Hold 집중 마력탄: 완료 시 28 피해 | Tap 마력 파동: 12 피해 |

일반·희귀·영웅·전설의 소켓 수는 1·2·2·3이다. 강화 +0~+3은 기존처럼 수치만 올린다. 지원 행동의 원본 판정 하나가 무기를 발동시키며 빗나가면 발사하지 않는다. 부채꼴 사격은 투사체 세 개로 표현하지만 합계 피해를 한 번만 적용한다. 피해와 승리는 기존 판정 시점에 확정하고, 투사체 도착은 시각적인 명중 시점이다.

각 등급 PNG는 가로로 배열한 **대기 / 준비 / 발사** 아틀라스다. 활은 당긴 시위와 풀린 시위, 석궁은 장전된 볼트와 빈 레일, 마도봉은 닫힘·충전·전개된 크리스털을 구분한다. 준비는 원래 몬스터 노트를 바라보며, 유지 행동은 접촉 중 충전을 유지한다. 실제 발동에서만 발사 컷을 보여준다. 장비 자체는 플레이어 곁에서 반동을 취하고 투사체가 몬스터로 이동한다.

| 항목 | 시간 |
|---|---|
| 짧은 준비 | 최대 0.20초, 빠른 곡에서는 0.45박 이내 |
| 발사 컷 | 최대 0.09초, 빠른 곡에서는 0.30박 이내 |
| 석궁 / 활 / 마도봉 투사체 비행 | 0.16 / 0.22 / 0.26초 |
| 명중 효과·몬스터 피격 반응 | 0.28초 |

## 이펙트 10종

`Assets/BBSB/Resources/BBSB/BattleVfx/`에 아래 이름의 PNG를 둔다. 밝은 단색 원본을 행동 색으로 물들여 사용한다.

| 파일 | 쓰임 |
|---|---|
| `slash.png` | 검·비검의 베기, 깃털·실 공격에 대한 반응 |
| `pierce.png` | 창·단검의 찌르기, 화살·볼트 명중 |
| `impact.png` | 해머·방패 타격, 적과 플레이어의 실제 피격 |
| `ring.png` | 공명·방어막·마력 충전·마력탄 명중 |
| `parry.png` | 튕김, 단단한 공격 방어, 흩어지는 파편 |
| `dodge.png` | Dive·Flick 회피 잔상 |
| `arrow.png` | 활 투사체 |
| `bolt.png` | 석궁 투사체 |
| `orb.png` | 마도봉 투사체 |
| `muzzle.png` | 원거리 발사 순간 섬광 |

몬스터 공격의 모양과 대응 행동을 함께 보고 반응을 고른다. 완전히 막은 피해는 방어막 효과를, 남은 실제 피해는 붉은 충격 효과를 사용한다. Burst·Scatter 공격은 작은 파편도 보여준다. 동일 공격의 기존 이동·파괴 연출과 함께 적용한다.

## 피격 정지와 흔들림

몬스터는 실제 무기 모션 또는 투사체가 도착하는 시점에 짧게 멈추고, 눌림·기울기·뒤로 튕김·붉은 플래시로 반응한다. 기존 몬스터 스프라이트에 적용하는 변형이므로 별도 피격 PNG가 없어도 동작한다. 새로운 Call이 시작되면 몸의 정지를 중단해 다음 전조를 보여준다.

플레이어는 실제 남은 피해가 있을 때 피격 정지와 반동을 적용한다. 새로운 입력 동작은 정지를 중단할 수 있다. 전투의 배경과 배우만 작게 흔들며 메뉴·이름·입력 영역은 고정한다. 방어막으로 전부 흡수하면 피해 정지·흔들림을 만들지 않는다.

정지는 한 번에 최대 65ms, 빠른 곡에서는 0.18박 이하로 제한한다. 동시에 여러 무기가 명중해도 가장 강한 반응 하나를 선택하며 강도와 정지 길이를 더하지 않는다. `Time.timeScale`, 오디오 재생, 입력 좌표, 판정 마감 시각을 변경하지 않는다.

## 구조와 검증

`RangedWeaponTimeline`, `WeaponMotion`, `BattleHitFeedback`, `BattleVfxCatalog`는 Unity 비의존 시간 함수다. `BattleVfxView`가 원본 판정·무기 발동 목록을 읽고 최대 96개 Sprite를 재사용한다. 이펙트는 피해를 만들지 않으며 일시정지·연습 반복에도 곡 시계와 같은 상태를 표시한다.

원거리 아틀라스는 `WeaponArt/{bow,crossbow,wand}/{common,rare,epic,legendary}.png`의 12개 파일이며 36개 동작·72개 동작별 소켓을 담는다. `WeaponSpriteCache`가 명세에 기록된 경계를 원본 픽셀로 반올림하여 나눈다. 대부분은 1/3씩이며, 희귀 마도봉과 전설 석궁은 각 자세가 온전히 들어오도록 실제 빈 여백을 경계로 사용한다. 이미지 자체를 다시 저장하거나 수정하지 않는다. 원거리는 최대 1024px, 이펙트는 최대 512px·RGBA32로 가져온다. 각 동작의 소켓·발사점·프레임 경계 좌표는 `RangedWeaponArtLayout`과 `battle-effects-manifest.json`에 함께 기록한다.

```bash
python Tools/validate_battle_effects.py
python Tools/validate_battle_effects.py /path/to/unzipped-pack
dotnet run --project Tools/CoreChecks/BBSB.CoreChecks.csproj --configuration Release
```

PNG 검사는 실제 알파, 빈 여백, 동작별 소켓 내부와 프레임 대응을 확인한다. CoreChecks는 11종 무기의 행동·등급·강화 조합, 충전·발사 분리, 부채꼴 사격의 단일 피해, 투사체 도착, 피격 정지 상한, 다음 Call 우선과 연습 초기화를 검사한다. PlayMode에는 실제 Sprite 슬라이싱·알파·이펙트 연결·일시정지·재사용 풀·흔들림 복귀 검사가 있다. 이 작업 환경에는 Unity Editor가 없어 PlayMode 실행과 실제 화면의 타격감 확인은 수행하지 못했다.

아틀라스는 Unity 6.3의 [Sprite.Create](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Sprite.Create.html)의 사각형 영역으로 나누고, UI에 불필요한 자동 물리 모양은 생성하지 않는다. 원본 비율을 유지하도록 [Sprite 임포트 설정](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/TextureImporter-npotScale.html)의 NPOT 크기 변환을 끈다.
