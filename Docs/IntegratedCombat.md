# 노트 조립·몬스터 전열·방패

기본 무기 연주 모드의 성장과 전투를 함께 적용한다. 보스의 무기 3택1, 처음부터 열린 7개 입력, 긴 공격 패턴과 짧은 방패 패턴은 유지한다. 노트 이동 곡선도 기존과 같다.

## 성장과 노트 조립

일반·엘리트 보상은 **아이템 / 증강 / 프레임 / 박자 주입**을 하나씩 제시하고 하나를 고른다. 상점도 같은 네 종류를 판매한다. 무기는 보스 보상으로 얻는다.

**메뉴 → 노트 조립**, 장비 화면 또는 전투 준비의 **노트 조립**으로 들어간다. 보유 무기와 원본 노트 번호를 고른 뒤 부품을 장착한다. 빛·어둠 및 시작 라인별 결과를 미리 볼 수 있다. 진행 중인 전투의 장비·노트는 일시정지나 준비 복귀 중에도 편집할 수 없다.

| 성장 축 | 이번에 추가한 내용 |
|---|---|
| 증강 | 힘의 리듬: 모든 공격 피해 +10%씩. 안정된 방어: 홀드 감소율 +5%p씩, 최대 +25%p. 짧은 쉼표: 쿨타임 -1박씩, 최대 -3박 |
| 프레임 | 강타: 해당 공격 피해 +50%. 회복: 성공 시 기본 회복 2. 후열 관통: 체력이 가장 적은 살아 있는 후열을 공격, 없으면 선봉 |
| 박자 주입 | 반박: 원본 끝 +0.5박에 60% 피해 Tap. 홀드: Tap을 0.5박 Hold로 바꾸고 피해 +40%. 교차: 다음 점유 라인에 원본 끝 +0.5박, 80% 피해 Tap |

원본 노트마다 프레임 하나와 주입 하나를 겹쳐 장착한다. **원본 패턴은 삭제하지 않는다.** 같은 칸의 부품을 교체하거나 다른 무기로 옮겨도 기존 부품은 가방에 남는다. 부품 하나를 두 무기에 동시에 장착할 수 없다. 획득한 부품과 장착 상태는 다음 필드에 유지하고 새 탐험에서 초기화한다.

추가 Tap은 원본 노트 성공이 선행 조건이다. 기존 장전·패링 등 선행 조건의 연결도 유지한다. 다른 입력과 겹치거나 패턴 끝을 넘는 주입은 이유를 표시하고 거부한다. 같은 원본 번호의 **모든 시작 라인·빛/어둠 패턴**에서 유효해야 장착할 수 있다. 혼돈의 전환 구간에는 부품을 적용하지 않는다. 회복은 판정·무기 강화에 따라 배율을 적용한다.

짧은 쉼표는 쿨타임만 줄이고 미완료 패턴이나 끝의 쉼을 줄이지 않는다. 기본 쿨타임이 1박 이상이면 최소 1박, 사용자 정의 0~1박 쿨타임은 늘리지 않는다. 패링으로 회복한 쿨타임은 계속 즉시 재사용한다.

## 몬스터 개별 HP와 교대

스테이지 총 HP를 몬스터 수로 나누어 개별 HP를 만든다. 합계는 기존 스테이지 HP와 정확히 같다. 일반 공격은 선봉 한 마리를, 후열 관통은 후열 한 마리를 공격한다. 초과 피해를 다른 몬스터로 넘기지 않는다. 피격·격파·그로기·공격 효과도 실제 대상에 연결한다. 모든 몬스터가 쓰러지면 승리한다.

선봉은 자신의 등록된 긴 패턴들을 순서대로 연주한다. 후열은 8박 간격의 짧은 Tap으로 개입하며 몬스터별 시작 시점을 2박씩 나눈다. 후열의 기본 피해는 판정 기본 피해의 75%(최소 1)다. 전열 역할은 공격을 예고할 때 고정하므로, 교대 후에도 보이던 노트의 방어 대상이 바뀌지 않는다.

기본 교대 판단은 선봉 진입 후 12박이다. 실제 교대는 **현재 +3박을 지난 다음 정박**(`floor(now + 3) + 1`)에 한다. 이미 보이는 노트의 시작점을 지우거나 앞당기지 않는다. 교대 경계를 넘는 홀드는 경계에서 끊고 잘린 시간의 피해는 없앤다. 반 박마다의 피해를 짧아진 구간에 몰아넣지 않는다. 격파 시에도 이미 예고한 구간에는 같은 규칙을 적용한다.

트릭스터가 난입하면 원래 선봉의 진행 위치를 저장한다. 트릭스터의 현재 구절이 끝난 뒤 원래 선봉으로 돌아와 저장된 위치부터 이어 간다. 홀드 중단 지점으로 복귀하면 남은 길이·남은 피해만 다시 예고한다. 기본 트릭스터는 `seesaw-goblin`과 `offbeat-goblin`이며 Monster Editor의 **전열 역할 직접 지정 → Standard / Trickster**로 다른 종도 설정할 수 있다. 원래 선봉이 죽었으면 살아 있는 다음 몬스터를 선택한다.

`FormationRules`의 예고 길이·교대 판단 간격·후열 간격을 조정할 수 있다. 전투 UI에는 선봉/후열, 개별 HP, 난입/복귀/교대까지 남은 박자를 표시한다. 일시정지와 긴 프레임에서도 같은 전투 시계를 사용한다.

## 간단한 방패 두 종류

총 무기는 32종, 방패는 6종이다. 방패는 빛·어둠·이면을 지원한다.

| 방패 | 조작과 효과 |
|---|---|
| 넓은 방패 (`wide-shield`) | 2라인. 물리적으로 왼쪽 입력은 선봉, 오른쪽 입력은 후열 방어. 각각 한 번 눌러 패링 및 2박 Hold, 피해 50% 감소, 기본 쿨타임 2박 |
| 축적 방패 (`resonance-shield`) | 1라인. 선봉에 대해 2박 Hold, 피해 50% 감소, 쿨타임 2박. 패링 대신 실제로 줄인 피해를 축적 |

넓은 방패의 홀드·해제·패링 회복·쿨타임은 두 입력이 독립적이다. 두 입력을 누른 채 멈췄다면 둘 다 다시 잡아야 재개한다. 신령 방울은 맞닿은 입력의 쿨타임만 회복하며 자동 방어를 만들지 않는다. 인접 쿨타임 감소 효과는 쉬고 있는 양쪽 입력에 적용하고 진행 중인 홀드는 유지한다. 사용자 정의 패턴도 각 입력에 짧은 Hold 하나와 누르기 패링을 사용한다.

기존 방패의 방어·패링은 선봉 공격에 대응한다. 넓은 방패 오른쪽 입력으로 후열까지 대응할 수 있다. 처음 붙잡은 적 홀드가 더 길면 원래 방어 시간을 넘어 적 홀드 끝까지 유지하고, 중간 진입도 남은 끝까지 유지한다. 최초 진입 판정으로 반 박마다 피해를 판정하며 해제 뒤에는 방어하지 않는다.

축적 방패는 **실제로 감소시킨 피해만**, 적 공격이 시작한 박자에 따라 빛/어둠에 나누어 모은다. 패링이나 더 강한 다른 방어가 막은 피해를 중복 적립하지 않는다. 기본값은 속성별 최대 24, 12를 소비해 **같은 박자 속성의 다음 유효 공격 한 번을 1.5배**로 만든다. 무기/혼돈의 해당 연주 구간 속성을 사용하고, 피해가 없는 입력에는 소비하지 않는다. 축적은 현재 전투 안에서 유지한다. 값은 `FiveLaneBattle.ResonanceThreshold / ResonanceCapacity / ResonanceAttackMultiplier`에서 조정한다.

## 이미지 설치

별도 전달한 `BBSB_Formation_Shields.zip`을 풀고 내부 `Assets` 폴더를 Unity 프로젝트 루트에 합친다. 새 무기 두 종의 실제 RGBA 투명 PNG와 `.meta`를 포함한다. 각 이미지는 2×2 아틀라스로 왼쪽 위 빛, 오른쪽 위 어둠, 왼쪽 아래 이면, 오른쪽 아래 빈 칸이다. 프레임·알파 검사·실제 그림 경계는 `formation-shield-art-manifest.json`에 기록한다. 이미지·음원은 Git에 추가하지 않는다.

## 검증 범위

`IntegratedCombatTests`에서 조립의 원본·선행 조건 유지, 부품 이동/해제, 교대 예고와 홀드 절단, 트릭스터 복귀, 개별 피해와 그로기, 긴 프레임/정지 동등성, 넓은 방패의 독립 입력, 방울 예약/쿨타임 지원, 실제 축적 피해를 검사한다. 기존 전체 Core 회귀 검사도 실행한다.

Unity PlayMode 검사에는 실제 노트 조립 버튼으로 장착/해제, 개별 HP 표시, 넓은 방패의 두 입력 재접촉, 역할 에셋 변환을 추가한다. 이 환경에는 Unity Editor가 없으므로 **Unity API 컴파일·PlayMode 실행·실제 화면/키감은 미확인**이다. C# 전체 구문 검사와 프리팹 구조 검사로 대체 실행을 주장하지 않는다.
