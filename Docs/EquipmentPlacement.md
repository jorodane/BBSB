# 무기 보유와 배치

기본 전투에서 `RunSession.OwnedWeapons`는 획득한 무기 인스턴스를 보유한다. 보상·상점 획득은 이 목록에 추가하며 배치를 자동 변경하지 않는다. 같은 종류를 두 번 획득하면 서로 다른 인스턴스다. 강화는 미배치 무기에도 적용할 수 있다.

`WeaponEquipment`의 배치는 기존 인스턴스 참조와 위치만 기록한다. 장착·이동·해제·겹침 교체는 인스턴스를 복사하거나 다시 만들지 않는다. `WeaponPlacement.Offset`는 점유 범위의 왼쪽 위치이고 `RequiredLanes`가 폭이다. 미배치는 해당 인스턴스의 배치 기록이 없는 상태다. 여러 라인을 점유해도 장착 무기 개수는 1개다.

장착 한도는 처음 2개이며 **보스 승리마다 1개, 최대 5개**다. 일반·엘리트 승리, 상점·휴식·강화 통과, 보상 선택에는 증가하지 않는다. 승리 티켓 중복 제출로도 증가하지 않는다. 다음 필드에서 보유·배치·한도를 유지하며 새 탐험에서는 초기화한다. 전투가 시작되면 일시정지·준비 복귀 중에도 현재 편성을 고정한다.

## 중심 드래그

편성 보드는 보유 목록 위에 고정되어 스크롤 중에도 보인다. 보유 무기의 드래그 버튼 또는 보드의 무기를 끌면, 무기 전체 폭의 중앙이 포인터를 따라간다. 무기를 선택하고 보드의 중심 위치를 클릭하는 방식도 지원한다.

물리 순서는 **S · D · F · Space · J · K · L**이다. D=0, F=1, Space=2, J=3, K=4, S=-1, L=5를 배치 좌표로 사용한다. 안정적인 입력 ID는 기존 D~K의 0~4를 유지하고 S=5, L=6을 쓴다. 입력 ID와 물리 위치를 혼동하지 않는다.

N라인 무기는 중심에 가장 가까운 **연속 N개**의 라인으로 스냅한다. 왼쪽 위치는 `floor(center - (N - 1) / 2 + 0.5)`이며 정확히 경계에 놓으면 오른쪽 후보를 택한다. 짝수 폭의 중심은 라인 사이에 있다. 위치를 강제로 화면 끝에 밀어 넣지는 않는다.

| 폭 | 놓는 중심 | 점유 |
|---|---|---|
| 1 | K | K |
| 2 | J와 K 사이 | JK |
| 2 | K와 L 사이 | KL |
| 2 | S와 D 사이 | SD |
| 3 | Space | F·Space·J |

유효한 배치가 다른 무기에 겹치면, **겹치는 무기의 배치 전체를 해제한 뒤** 새 위치를 적용한다. 한 라인만 겹쳐도 기존 복수 라인 무기의 나머지 라인을 남기지 않는다. 인스턴스는 보유 목록에 그대로 남는다. 교체 후 장착 개수로 한도를 검사하므로 한도가 가득 차도 교체할 수 있다.

잠긴 라인, 범위 초과, 잘못된 폭, 교체 후 한도 초과는 전체 작업을 취소한다. 미리보기는 배치를 바꾸지 않는다. 모든 조건을 통과한 뒤 한 번에 반영하므로 실패한 드롭에서 일부 무기만 해제되지 않는다.

## S/L 확장

S와 L은 기본 잠금이며 이번 변경에서 해금 보상을 지정하지 않는다. 미래 진행 규칙은 `RunSession.UnlockInputExtensions(...)`로 좌우를 독립 해금할 수 있다. 보스의 장착 한도 증가와 확장 해금은 별개다.

해금 후에도 **1라인 무기는 S/L에 배치할 수 없다.** 복수 라인 무기의 연속 범위가 해당 위치를 포함할 때만 사용한다. 별도의 좌/우 확장 선택 옵션은 없으며 중심과 폭으로 SD 또는 KL 등을 결정한다. 해금되어도 입력 위치가 장착 개수 한도를 늘리지는 않는다.

## 시작 Offset별 패턴

장착 수의 단위와 입력 동작은 분리한다. `PhraseLane`는 한 장착 인스턴스의 전투 진행 상태이며 `LaneAt(inputId)`로 물리 입력을 찾는다. 입력을 합쳐 같은 키로 취급하지 않는다.

점유한 라인을 왼쪽부터 0, 1, ...로 센다. Ready 상태에서 누른 라인의 Offset으로 `WeaponPhraseSet.Starts[offset]`을 선택한다. JK 장비는 J에서 시작하면 0번, K에서 시작하면 1번 패턴이다. KL 장비는 K=0, L=1이다. 각 패턴은 박자·피해·패링·홀드 감소율·피니셔·반복·쿨타임을 별도로 가질 수 있다. 활성 패턴과 쿨타임 도중 다른 라인으로 새 패턴을 시작할 수는 없다.

`WeaponPhraseAuthoring.startLaneOffset`으로 시작 패턴을 지정한다. 에셋 키는 무기 ID + 시작 Offset이다. `notes.laneOffset`은 시작 라인을 기준으로 한 상대 위치이며 점유 범위 안에서 순환한다. 첫 노트는 0, 이후 노트는 다른 점유 라인으로 보낼 수 있다. 입력 판정과 실제·예고 노트가 같은 매핑을 쓴다. 홀드 종료는 실제로 홀드를 시작한 라인의 떼기만 받으며 일시정지 복귀도 그 입력을 요구한다.

봉(`staff`)은 실제 보상·상점에 등장하는 2라인 무기다. 시작한 쪽에서 0 / 0.5박 Tap 후 반대쪽에서 1~2박 Hold를 연주한다. 오른쪽 시작은 같은 상대 Offset 규칙으로 좌우가 뒤집힌다. 신령 방울(`spirit-bell`)은 1라인이며 인접 무기의 맞닿은 라인을 시작 Offset으로 사용한다. 예약 시점이 아닌 실행 시점에 진행 중인 패턴을 검사한다. [예약 발동 규칙](FiveLaneCombat.md#신령-방울의-예약-발동)을 참고한다.

추가 무기는 `WeaponDefinition.RequiredLanes` 또는 생성 시 `WeaponState`의 명시적인 폭으로 지정할 수 있다. 쌍검은 기존 1박 단검 동작을 계승하는 1라인 무기이고, 전용 스프라이트 전까지 두 자루의 코드 실루엣으로 표시한다.

기존 Call & Response 모드의 자동 발동 장비 규칙은 별도 경로를 유지한다.
