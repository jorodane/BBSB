# 기본 박자 반복과 긴 무기 패턴

**단검은 2박마다 Tap 한 번, 쌍검은 매 박자 Tap 한 번을 무한 반복한다.** 초기 플레이어가 일정한 기본 박자를 익히는 무기이며, 성공·반미스에는 쉬지 않고 다음 입력으로 이어진다. 미스가 나면 반복을 끊고 2박 뒤 다시 시작할 수 있다. 기본 피해는 둘 다 6이며 강화·등급으로 기본 입력 간격을 바꾸지 않는다.

공격·지원 26종 중 이 두 무기를 제외한 24종은 8~12박의 긴 구간을 사용한다. 단발 무기는 완주 후 6~10박 쿨타임을 거쳐 다시 누르고, 혼돈의 진자는 반복·전환한다. 기존 방패 4종은 짧은 패턴·쿨타임·패링 회복·홀드 방어를 유지한다. 새 넓은 방패·축적 방패도 짧은 대응 패턴을 사용해 방패는 총 6종이다. [통합 전투 규칙](IntegratedCombat.md)을 참고한다.

빛은 정박, 어둠은 엇박에 입력이 더 많이 놓인다. 시작점을 포함해 **누르기와 Hold 해제의 2/3 이상**이 선택한 속성의 박자다. 상대 정수 박자에 배치한 주 리듬은 빛에서 정박, 어둠에서 `n + 0.5`가 되고, 반박 악센트는 소수로 남긴다. 이면은 시작 박자가 고른 쪽을 따른다.

표의 수치는 기본 강화·Perfect 기준이다. 미스 후에는 이미 생성된 나머지 입력을 유지하고 마지막 판정부터 같은 길이의 미스 쿨타임을 센다. 완주 쿨타임은 구간의 끝부터 센다. 활·석궁의 발사는 자기 장전만 선행 조건으로 사용한다. 앞 장전에 실패해도 뒤 장전을 성공하면 뒤 발사를 할 수 있다.

## 혼돈의 두 진행 방식

- 기존 반복형 **단검·쌍검·혼돈의 진자**: 혼돈에서는 각각 2박·1박·8박의 기본 구간을 반복한다. 같은 박자를 6박 이상 성공적으로 연주한 뒤 구간 경계에서 25% 확률로 4.5박의 전환 패턴에 진입한다. 전환을 완료하면 반대 속성의 박자로 기본 반복을 재개한다. 단검·쌍검의 일반 속성에는 전환 구간이 없다.
- 새로 혼돈을 허용한 **공격·지원 21종**: 각 8~12박짜리 두 구간을 연주한다. 첫 구간과 둘째 구간의 빛/어둠은 각각 50%로 독립 추첨하므로 네 조합이 모두 가능하다. 전환 패턴은 없으며 두 구간을 마친 뒤 원래 쿨타임에 들어간다. 구간 사이 박자가 달라지면 겹침 없이 반박 쉬고 다음 구간을 시작한다.
- 방패는 빛·어둠·이면의 짧은 대응 패턴을 유지한다. 양면 지팡이·일식 거울의 이면 전용 속성도 유지한다.
- 첫 입력은 무기 호출이다. 추첨한 위상과 무기별 대기 시간을 적용해 첫 노트를 예약하며, 첫 노트부터 일반 판정을 적용한다. 다음 구간에는 호출 대기를 다시 추가하지 않는다. 한 구간에서 미스가 나면 그 구간의 남은 확정 노트까지만 유지하고 다음 구간·전환은 취소한다. 반미스는 연결할 수 있다.
- 혼돈 효과는 기존과 같이 1.5배다. 현재 활성 박자는 `ActiveSide`, 소유 무기 속성은 계속 `Chaos`다. 전투 시드와 활성화 번호를 공유하므로 미리보기·실제 판정·일시정지·예약 발동이 재추첨하지 않는다.

## 구현과 이미지

패턴은 `Core/LongWeaponPatterns.cs`, 무기 정의·라인 폭은 기존 `WeaponCatalog` / `WeaponExpansion`에 있다. `WeaponPhrase.MaximumCycles`는 0이면 무한 반복, 양수면 기본 구간 수 제한이며 `Repeat`와 함께 사용한다. 혼돈 기본 패턴은 모든 시작 Offset·박자에서 `Repeat=true`, `MaximumCycles=0`(전환형) 또는 `2`(무작위 두 구간형)로 통일한다. Inspector의 `maximumCycles`도 같은 뜻이다. 전환형 기본 길이는 정수, 전환 길이는 `n + 0.5`다. 기존 단일 Tap 사용자 정의 반복 패턴의 1.5박 기본 전환은 호환용으로 남아 있다.

현재 속성 PNG에는 새로 활성화한 21종의 혼돈 그림이 이미 포함되어 있다. 별도 생성·배경 제거 없이 기존 RGBA 원본을 사용한다. 전달 ZIP은 21개 전체 속성 PNG와 기존 `.meta`, 프레임 정보, 설치 설명을 담는다. 원거리 3종은 대기·준비·발사 3프레임을 포함한다. 코드는 Git으로, 이미지 팩은 별도 전달하며 기존 30종 이미지가 설치되어 있으면 다시 복사할 필요가 없다.

`LongWeaponPatternTests`는 실제 카탈로그의 단검·쌍검으로 장시간 반복, 반미스·일시정지 후 박자 유지, 미스 시 예고 파괴·2박 대기·재시작을 검사한다. 단발 무기의 완주/쿨타임, 속성 박자 비중, 21종의 두 구간 종료, 네 추첨 조합과 예고 일치, 세 무한 반복형의 전환도 검사한다. `FiveLaneNoteTimelineTests`의 단검·쌍검 검사는 실제 기본 데이터로 3박 예고를 확인한다. 다른 짧은 메커니즘 시험은 `ShortWeaponPhrases`의 고정 예제를 사용한다.
