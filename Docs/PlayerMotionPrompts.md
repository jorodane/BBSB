# Player motion generation prompts

Mode: built-in `image_gen`. The reference (`Docs/Art/player-reference.png`) and eight final source PNGs are excluded from this upload. Their intended texture directory is `Assets/BBSB/Resources/BBSB/BattleArt/PlayerMotion/`. The existing player portrait remains active until all eight atlases are installed.

The initial transparency requests returned RGB images with a painted checkerboard. Those drafts are not used by the game. Five accepted atlases were regenerated with solid chroma green; the three punch atlases were generated separately to make the punching arm and failed trajectory distinct. `PlayerMotionImporter` composites and packs the source images at Unity import. There is no runtime background-removal shader.
