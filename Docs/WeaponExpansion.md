# 무기 확장: 일반 10종 + 이면·혼돈 전용 3종

기존 17종에 13종을 추가해 총 30종이다. 모두 보상·상점·편성·전투에서 같은 무기 ID를 사용한다. 획득은 보유 목록에만 추가하며 자동 장착하지 않는다. 장착 개수 제한, 중심 드래그 배치, S/L 확장과 시작 Offset 규칙은 그대로 적용된다.

## 일반 무기 10종

일반 10종은 빛·어둠·이면·혼돈으로 획득한다. 빛·어둠·이면은 8~12박 한 구간과 6~10박 쿨타임, 혼돈은 빛/어둠을 독립 추첨하는 두 구간과 같은 쿨타임을 사용한다. 최신 무기별 박자·지원량·쿨타임 표는 [긴 무기 패턴](LongWeaponPatterns.md)에 정리했다.

| 무기 / ID | 라인 | 특징 |
|---|---:|---|
| 레이피어 `rapier` | 1 | 빠른 이중 찌르기와 마지막 강한 찌르기 |
| 전투 도끼 `battle-axe` | 2 | 교대 타격과 긴 Hold 내려찍기 |
| 사슬낫 `chain-sickle` | 2 | 던지기·당기기를 두 묶음으로 연결 |
| 철선 `war-fan` | 1 | 펼치고 접는 반박 베기 |
| 미늘창 `halberd` | 3 | 시작 Offset에 따른 횡단·되돌리기·끝 라인 강타 |
| 전쟁 북 `war-drum` | 3 | 행진 타격과 두 번의 양옆 무기 호출 |
| 소리쇠 `tuning-fork` | 2 | 교대 공명과 Hold로 양옆 쿨타임 감소 |
| 군기 `war-banner` | 2 | 두 번의 Hold와 양옆 다음 타격 강화 |
| 향로 `censer` | 1 | 세 번의 Hold 회복과 중간 타격 |
| 차크람 `chakram` | 2 | 긴 왕복과 반박 가속 |

## 속성 전용 3종

| 무기 / ID | 속성 / 라인 | 효과 |
|---|---|---|
| 양면 지팡이 `twilight-staff` | 이면 / 2 | 10박의 회복 의식 또는 충전·마력 공격 |
| 일식 거울 `eclipse-mirror` | 이면 / 1 | 8박의 쿨타임 감소·회복 또는 공격 강화·타격 |
| 혼돈의 진자 `chaos-pendulum` | 혼돈 / 3 | 8박 세 라인 왕복을 무한 반복. 4.5박 연결 후 반대 박자로 전환 |

전용 무기는 생성·보상·상점에서 해당 속성만 선택한다. 혼돈의 진자는 유지 6박 이상, 패턴 경계에서 25% 전환, 효과 ×1.5 규칙을 유지한다. 0박 시작 시 7박 마지막 노트 성공 후 8박부터 첫 전환이 가능하고, 전환을 끝내면 12.5박부터 반대 박자로 이어진다. 단검·쌍검도 혼돈일 때 무한 반복한다.

## 지원과 판정

- 양옆은 **무기 전체 점유 범위 바깥의 바로 인접한 라인**이다. 빈 라인을 건너뛰지 않는다. S/L을 차지한 복수 라인 무기도 대상이 되며 효과는 무기당 한 번 적용한다.
- 전쟁 북은 신령 방울과 같은 예약을 사용한다. 1박 뒤 대상 속성에 맞는 박자로 맞추고 쿨타임을 무시한다. 그때 이미 진행 중인 패턴은 유지한다. 입력을 자동 성공시키지 않는다.
- 쿨타임 감소는 대기 중인 쿨타임에만 적용한다. 진행 중인 패턴·홀드·다음 노트 시각은 바꾸지 않는다.
- 공격 강화는 다음 **실제 피해 노트 한 번**에 적용한다. 회복·지원·실패는 소모하지 않지만 만료 시각부터 효과가 없다. 중첩 곱셈 없이 더 강한 수치와 더 늦은 만료 시각만 유지한다.
- 일반적인 강화 배율, 반미스 배율, 혼돈 배율은 피해·회복·지원 수치에 반영된다. 표시 수치는 기본 등급·강화 0·Perfect 기준이다.
- 패턴 노트를 놓쳐도 나머지 확정 노트는 끝까지 칠 수 있다. 조건부·반복 예고 표시와 3박 표시 범위는 기존 규칙을 따른다.

무기 정의는 `WeaponExpansion.cs`, 패턴은 `LongWeaponPatterns.cs`, 시작 Offset/박자별 선택은 `WeaponPhraseSet`과 `WeaponPhraseAuthoring`, 지원 효과 처리는 `FiveLaneBattle`에 있다. 이미지 설치는 [WeaponArt.md](WeaponArt.md#속성-이미지와-13종-무기-확장-팩)를 참고한다.
