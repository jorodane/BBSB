# 무기 확장: 일반 10종 + 이면·혼돈 전용 3종

기존 17종에 13종을 추가해 총 30종이다. 모두 보상·상점·편성·전투에서 같은 무기 ID를 사용한다. 획득은 보유 목록에만 추가하며 자동 장착하지 않는다. 장착 개수 제한, 중심 드래그 배치, S/L 확장과 시작 Offset 규칙은 그대로 적용된다.

아래 박자는 패턴을 시작한 기준 시각부터 센다. `Hold 1→2`는 1박에 누르고 2박에 끝나는 홀드다. 모두 기본적으로 단발이며 빛·어둠·이면으로 획득할 수 있다.

## 속성 전용 3종

| 무기 / ID | 속성 / 라인 | 효과 |
|---|---|---|
| 양면 지팡이 `twilight-staff` | 이면 / 2 | 정박: 시작 쪽 Tap 회복 2 → 반대쪽 Hold 1→2 회복 4. 엇박: 같은 입력으로 피해 10 / 26 |
| 일식 거울 `eclipse-mirror` | 이면 / 1 | 정박: Tap 0으로 양옆 쿨타임 -1박 → Tap 1로 회복 2. 엇박: Tap 0으로 양옆 다음 공격 +50%를 3박 부여 → Tap 1로 피해 10 |
| 혼돈의 진자 `chaos-pendulum` | 혼돈 / 3 | 세 라인 Tap 0 / 1 / 2 반복, 기본 피해 8 / 8 / 12. 전환은 0 / 0.5 / 1 / 1.5 / 2에 시작→다음→끝→다음→시작, 기본 피해 7 / 7 / 7 / 7 / 12 |

전용 무기는 생성·보상·상점에서 해당 속성만 선택한다. 혼돈의 진자는 기존 혼돈 규칙(유지 6박 이상, 패턴 경계에서 25% 전환, 효과 ×1.5)을 사용한다. 0박 시작 시 기본 패턴의 8박 노트까지 성공하면 9박부터 첫 전환이 가능하며, 전환 후 11.5박부터 반대 박자로 이어진다. 반복 허용 기본 무기는 단검·쌍검·혼돈의 진자다.

## 지원과 판정

- 양옆은 **무기 전체 점유 범위 바깥의 바로 인접한 라인**이다. 빈 라인을 건너뛰지 않는다. S/L을 차지한 복수 라인 무기도 대상이 되며 효과는 무기당 한 번 적용한다.
- 전쟁 북은 신령 방울과 같은 예약을 사용한다. 1박 뒤 대상 속성에 맞는 박자로 맞추고 쿨타임을 무시한다. 그때 이미 진행 중인 패턴은 유지한다. 입력을 자동 성공시키지 않는다.
- 쿨타임 감소는 대기 중인 쿨타임에만 적용한다. 진행 중인 패턴·홀드·다음 노트 시각은 바꾸지 않는다.
- 공격 강화는 다음 **실제 피해 노트 한 번**에 적용한다. 회복·지원·실패는 소모하지 않지만 만료 시각부터 효과가 없다. 중첩 곱셈 없이 더 강한 수치와 더 늦은 만료 시각만 유지한다.
- 일반적인 강화 배율, 반미스 배율, 혼돈 배율은 피해·회복·지원 수치에 반영된다. 표시 수치는 기본 등급·강화 0·Perfect 기준이다.
- 패턴 노트를 놓쳐도 나머지 확정 노트는 끝까지 칠 수 있다. 조건부·반복 예고 표시와 3박 표시 범위는 기존 규칙을 따른다.

데이터는 `WeaponExpansion.cs`, 시작 Offset/박자별 선택은 `WeaponPhraseSet`과 `WeaponPhraseAuthoring`, 지원 효과 처리는 `FiveLaneBattle`에 있다. 이미지 설치는 [WeaponArt.md](WeaponArt.md#속성-이미지와-13종-무기-확장-팩)를 참고한다.
