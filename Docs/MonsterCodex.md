# 몬스터 도감

시작 화면의 **몬스터 도감**, 탐험 메뉴, 전투 일시정지 메뉴에서 같은 도감을 연다. 아직 탐험을 시작하지 않아도 12종·24개 패턴을 모두 볼 수 있다.

목록에는 아이콘과 이름만 표시하며 화면 폭에 따라 열 수가 바뀐다. 상세 헤더는 종족 아이콘과 이름, 본문 왼쪽은 캐릭터·공격 재생, 오른쪽은 **평상시 → 각 패턴** 순서의 아이콘·이름 목록이다. 목록으로 돌아가면 이전 스크롤 위치를 유지한다. Escape는 상세에서 목록으로, 목록에서 원래 메뉴로 돌아간다.

## 재생과 반응 안내

- 패턴을 고르면 한 박 준비 후 Call부터 반복한다. 재생/멈춤, 다시 보기, 소리 켜기/끄기, 60–200 BPM 조절을 지원한다. 평상시를 고르면 패턴 재생과 소리를 정리한다.
- 첫 Call을 **1박**으로 센다. `clock-seven-beat-wait`는 8박에 Tap, `offbeat-single-tap`은 4.5박, `offbeat-pair`는 3.5·4.5박에 Tap한다. 입력 구간은 실시간 문구, 타임라인과 박자 목록으로 안내한다. 왼쪽 전투 미리보기 영역을 누르거나 드래그하면 플레이어가 반응하고 PERFECT·반미스·MISS를 바로 표시한다.
- Hold는 끝까지 유지, Dive는 유지 후 끝 박에 떼기, Flick은 미리 누른 뒤 해당 박에 튕겨 떼기, Shake는 목표 시점 전후의 반미스 허용 범위 안에 한 번 왕복하면 Perfect, 완료하지 못하면 Miss다. 상세 설명에 현재 BPM의 ±허용 시간을 표시하고 타임라인에 짧은 입력 범위를 보여준다.
- `MonsterPreview`는 원래 `MonsterPatternDefinition`으로 독립된 라운드를 만들고 실제 `RhythmRound`의 Press/Move/Release로 판정한다. 전투와 같은 `BattleArenaView`가 플레이어 모션·반격·몬스터 피격·공격 이미지를 보여준다. HP·보상은 본 게임에 반영하지 않는다. 패턴 종료 시 새 판정 상태로 자동 반복하며 결과 화면으로 전환하지 않는다. 화면·이미지 슬롯·오디오 객체는 반복마다 재생성하지 않는다.
- 도감 미리보기도 누른 채 멈추면 재생 후 다시 접촉해야 입력을 이어간다. 메뉴 버튼과 패턴 목록은 반격 입력 영역 밖에 있다.
- 자동 반복에서는 마우스·터치의 눌림과 드래그를 이어간다. 누른 시간과 이동 기록도 다음 반복의 시계에 맞춰 옮기며, 반복 시작을 새 Tap이나 Hold 시작 판정으로 처리하지 않는다. 반복 경계에서 누르거나 떼는 입력도 한 번 처리한다. **다시 보기**, 패턴·템포 변경은 입력까지 초기화한다.
- 하피의 세 갈래 깃춤은 Call 1·2.5·4박 → Tap 5·6.5·8박이다. 짧은 깃춤은 Call 1박 → Tap 2박이다. 각 깃털은 해당 Call에 출발하며 세 갈래 깃춤의 이동 시간과 속도는 같다.
- 네코마타는 선택한 한 패턴을 재생한다. 전투의 정박/엇박 연결 묶음 전체를 재생하는 기능은 아니다.
- 전투에서 열면 기존 DSP 시계·입력·판정은 일시정지 상태를 유지한다. 닫아도 메뉴에 남고 **이어하기**를 눌러 재개한다. 누르고 있었다면 기존 재접촉 절차를 유지한다. 미리보기 소리와 시계는 독립적이며 닫기·패턴 변경 때 정리한다.
- 탐험·일시정지 메뉴의 `CanvasGroup`은 공통 모달 생성 시 붙인다. 도감이 열린 동안 메뉴의 입력과 레이캐스트를 차단하고, 닫으면 원래 메뉴의 입력을 복구한다.

## 이미지 넣기

`Upload Monster Images` 커밋(`ced553b`)의 도감 아이콘 36개와 본체·공격 PNG 316개가 연결되어 있다. 파일별 대응은 [MonsterCodexIcons.json](MonsterCodexIcons.json)과 [MonsterArtFiles.json](MonsterArtFiles.json)에 있다.

| 용도 | 파일 경로 |
|---|---|
| 그리드·상세 헤더·평상시 아이콘 | `Assets/BBSB/Resources/BBSB/Codex/Monsters/{monster-id}.png` |
| 패턴 아이콘 | `Assets/BBSB/Resources/BBSB/Codex/Patterns/{pattern-id}.png` |
| 왼쪽 본체·공격 모습 | 기존 `Assets/BBSB/Resources/BBSB/BattleArt/MonsterAttacks/` 경로 |

새 얼굴 초상 12개와 기존 공격 장면을 활용한 패턴 아이콘 24개를 사용한다. 본체와 공격은 앞서 배포한 `BBSB_AllMonsterArt.zip`을 그대로 사용한다. 새 도감 아이콘이 없으면 본체/공격 이미지로, 본체도 없으면 기존 전투 이미지 또는 이름으로 표시한다.

도감과 전투는 `MonsterAttackSprites`의 같은 파일 조회 코드를 사용한다. 이미지가 필요한 순간에 정확한 Resources 경로에서 읽어 캐시하며, 평상시 본체 한 장을 위해 다른 패턴 폴더 전체를 로드하지 않는다. 인형의 `travel-0`~`travel-3`은 번호순으로 반복한다. PNG 한 장은 한 포즈이며, Single 이미지에 남아 있는 자동 슬라이스 이름은 모션 프레임으로 사용하지 않는다.

도감 본체도 업로드된 Sprite 피벗으로 지면을 잡는다. 공격의 배율·출발/도착 오프셋·이미지 오프셋·상태별 피벗/회전·프레임 속도는 전투와 같은 `MonsterAttacks/Display.asset`을 읽는다. 도감의 무대 크기와 반응 위치는 미리보기 레이아웃에 맞춘다.

`MonsterCodexImporter`는 새 PNG를 Single Sprite, 입력 알파 유지, Clamp, Bilinear, 밉맵 없음, 압축 없음, 최대 256으로 임포트한다. 이미 Sprite로 조정한 파일은 설정을 유지한다. 원본 PNG를 자르거나 배경을 제거하지 않는다. 본체·공격의 기존 임포터와 경로는 그대로다.

## 검증

`Tools/CoreChecks`의 `MonsterPreviewTests`는 모든 종족·패턴과 60/120/200 BPM에서 Call과 입력 간격, 공격의 정시 도착, 긴 쉼과 엇박 표시, Dive 끝 떼기, 회복 구간, 반복 시점, 다른 라운드와의 분리를 검증한다.

`NamedResourceClipsTests`는 파일 경로 조회, 불필요한 폴더 로드 방지, 번호 프레임 우선순위/반복, Call 번호 분리, 기존 명명된 아틀라스 호환을 검증한다. Unity의 `MonsterArtIntegrationTests`는 실제 Resources에서 아이콘 36개·본체 호출 95개(하피 call-0 재사용 2회 포함)·현재 사용 공격 이미지 211개를 로드하고, 모든 패턴의 보이는 상태와 정시 도착이 해당 이미지에 연결되는지 검사한다.

Unity PlayMode에는 시작 전 도감 탐색/평상시 복귀/메뉴 복귀, 직접 입력의 판정과 반격, 반복 중 객체 재사용, 전투를 누른 채 멈추고 도감을 열었다 닫는 경우의 시계·HP·재접촉 보존 검사를 추가했다. 이 환경에서는 Unity Editor를 실행할 수 없어 PlayMode 실행과 실제 기기의 화면·소리 확인은 별도 확인이 필요하다.

## 무기 배치 연습

준비 화면의 무기 배치 연습은 같은 계획을 무한 반복한다. 종료 보고서 없이 매회 판정·체력·무기 연속 발동/방어막 상태만 초기화하며 배치와 음소거 설정은 유지한다. 메뉴의 **배치로 돌아가기**로 종료한다. 본 게임의 체력·보상·배치를 변경하지 않는다.

도감과 무기 배치 연습의 자동 반복은 `RhythmRound.Repeat`의 공통 처리를 사용한다. 눌림·드래그를 다음 반복 시계로 이어받고, 반복 경계의 누르기·떼기·일시정지 전에 라운드를 전환한다. 실전 전투의 패턴 전환은 같은 라운드에서 진행되어 입력을 초기화하지 않는다. 전투 종료와 메뉴 재접촉 절차는 별개다.

도감 무한 연습 변경 당시 검증: 순수 C# 검사 201개 통과. Core·Runtime·PlayMode 테스트 소스의 참조 컴파일도 확인했다. 컴파일에는 Unity 2021.3 참조 DLL, 공식 uGUI 2018.4 소스의 참조용 호환 수정, Input System/Unity 6 GetMesh API의 컴파일용 대체 선언을 사용했다. Unity 6000.3.5f2의 실제 임포트·PlayMode 실행·오디오 재생을 대체하는 검증은 아니다.
