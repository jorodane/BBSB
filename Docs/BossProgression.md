# 보스 무기 선택과 다음 필드 진행

기본 무기 연주 모드는 **시작 무기 두 개에 익숙해진 뒤, 보스마다 무기 하나를 추가**하는 흐름을 사용한다.

| 시점 | 보상과 변화 |
|---|---|
| 시작 편성·새 탐험 | S·D·F·Space·J·K·L 전부 사용 가능. 시작 장착 한도 2개 |
| 일반·엘리트 승리 | 기존 골드 + 아이템/증강/프레임/박자 주입 중 하나 선택. 무기는 제시하지 않음 |
| 상점 | 아이템·증강·프레임·박자 주입 판매. 무기는 판매하지 않음 |
| 보스 승리 | 골드 60, 장착 한도 +1(최대 5), 서로 다른 무기 3종 제시 |
| 보스 무기 선택 | 하나를 보유 목록에 추가. 속성·등급은 제시한 값 그대로, 강화는 0. 자동 장착하지 않음 |
| 필드 완료 | 무기 편성 버튼으로 새 무기를 배치한 뒤 다음 필드로 출발 |
| 다음 필드 | 체력·최대 체력·골드·장비 인스턴스·강화·편성·아이템·증강·노트 부품과 조립 상태·장착 한도 유지 |
| 사망·탐험 종료 후 새 탐험 | 획득 보상 초기화. 캐릭터의 시작 무기와 저장된 시작 편성 복원. 7개 라인은 계속 개방 |

보스 무기 선택은 건너뛸 수 없고, 선택 전에는 다음 필드로 넘어갈 수 없다. 하나를 선택하면 나머지 제안은 사라지며 추가 선택·중복 승리 콜백으로 무기나 장착 한도를 중복 지급하지 않는다. 보스 선택에서 골드를 소비하지 않는다. 무기 장착 한도가 5에 도달해도 이후 보스의 3택1은 계속 제공하고, 보유한 장비 중 사용할 무기를 편성한다.

후보는 가능한 한 아직 보유하지 않은 무기 종류를 우선한다. 서로 다른 무기 ID 세 개를 고른 뒤 각 후보의 속성과 등급을 한 번 추첨한다. 미보유 종류가 세 개보다 적으면 이미 가진 종류를 섞어 세 후보를 채운다. 화면을 다시 열거나 잘못된 선택을 시도해도 후보를 다시 추첨하지 않는다. 맵 난수와 보상 난수는 기존처럼 분리한다.

S/L은 복수 라인 무기의 끝부분에 사용한다. **1라인 무기는 D·F·Space·J·K, 복수 라인 무기는 S/L을 포함한 연속 범위**에 놓는다. 무기 한 개가 여러 라인을 차지해도 장착 개수는 하나이며, 점유 라인은 각각 직접 입력한다. 별도의 라인 해금 비용이나 보상은 없다.

이 문서의 다음 필드는 **현재 탐험 안의 다음 보스 구간**이다. 완전히 새로운 탐험에 획득 무기를 넘기는 영구 계승은 추가하지 않는다. 캐릭터와 시작 무기 배치를 기억하는 기존 저장은 [탐험 시작 준비](RunSetup.md)를 따른다.

구현은 `RunSession.GenerateOffers` / `ChooseReward` / `AdvanceField`, 라인 개방은 `WeaponEquipment.Reset`, 보상·편성 버튼은 `RunPresenter`에 있다. `IsBossWeaponReward`가 필수 선택 상태를 제공한다. 이전 Call & Response 모드는 기존 보상·상점 규칙을 유지한다.

Core 검사는 전 라인 개방·저장 편성 복원·전투 입력, 일반/엘리트/상점 무기 제외, 보스 3종과 단일 선택, 다음 필드의 상태 보존, 후보 재현과 전체 도감 보유 시 대체 후보, 사망·오래된 콜백 차단을 확인한다. Unity PlayMode에는 실제 세 카드·건너뛰기 제거·중복 클릭·편성 및 다음 필드 버튼 검사를 추가했다.
